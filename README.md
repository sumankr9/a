# Personal Portfolio Website

A small, responsive personal portfolio website built with HTML and CSS.

## Files

- `index.html` - page content and structure
- `style.css` - layout, colors, and responsive styling

## Preview

Open `index.html` directly in a browser, or run a local server from this folder:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customize

Replace the placeholder text, project descriptions, email address, and "Your Name" in `index.html` with your own details. Update the colors near the top of `style.css` if you want a different theme.
